# IRIS-OS V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver IRIS-OS V2 as independently verified vertical slices.

**Architecture:** Extend the existing Drizzle repositories and AI runtimes
around a shared runtime context and context planner. Persist activity before
asynchronous PgBoss processing, and protect large behavior changes with
server-side feature flags.

**Tech Stack:** Next.js 16, TypeScript, React 19, Drizzle/PostgreSQL, Vercel AI
SDK, PgBoss, Zod, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-08-14-iris-os-v2-design.md`

## Global Constraints

- Existing threads remain global until explicitly assigned to a workspace.
- Workspace V2 is owner-only and all ownership checks are server-side.
- Stored thread scope is authoritative after thread creation.
- Memory scope applies to the entire graph and retrieval pipeline.
- Existing agent, skill, workflow, MCP, and memory runtimes are extended.
- Learning never blocks chat streaming or grants permissions.
- PgBoss and PostgreSQL remain the durable job foundation.
